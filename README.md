# Semiconductor Learning

A tiny Android app that teaches semiconductors in six short lessons, each with a quiz question.

- Plain Java, one Activity, no libraries.
- The APK is built by GitHub Actions on every push: open the run, scroll to **Artifacts**, download the zip and install `app-debug.apk`.

Lessons: what a semiconductor is, doping, the diode, the transistor, chips, and how chips are made.
